Welcome to the MVL Benchmark Library

The MVL Benchmark Library is an online resource for benchmarks in the domain of multi-valued logic (MVL) design and verification. It provides a database of benchmark specifications {% if only_alu %}— starting with arithmetic-logic units defined over finite algebraic structures such as GF(p), GF(pⁿ) and Z/kZ, with register files and processors to follow —{% else %}— arithmetic-logic units, register files and processors defined over finite algebraic structures such as GF(p), GF(pⁿ) and Z/kZ —{% endif %} together with reference implementations in C, Python, Verilog and VHDL, all given in a common benchmark format.

Every implementation is compiled, simulated and compared digit-wise against an independent golden model before publication. Each entry carries its own verification record — test strategy, toolchain versions, random seed and file checksums — so that results can be reproduced.

The library is maintained by the Group of Computer Architecture (AGRA) at the University of Bremen and is open to contributions from the MVL community. Whether you design ternary arithmetic, study Galois-field hardware or evaluate verification tools, we invite you to browse, download and contribute benchmarks. Submissions pass an automated review pipeline followed by maintainer approval; new benchmarks can also be derived with our LLM-based generator.

To learn more, see the About page and the format documentation. If you use the library, please cite our ISMVL 2026 paper.
