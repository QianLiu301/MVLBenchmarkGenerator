An Online Resource for Multi-Valued Logic Benchmarks

Reference specifications and implementations for MVL research, in C, Python, Verilog and VHDL — each checked against an independent golden model and published with a reproducible verification record.

Browse library Submit a benchmark Download by selection

The MVL Benchmark Library collects specifications and reference implementations of multi-valued logic designs — starting with arithmetic-logic units over Z/kⁿZ (radix-k integer arithmetic) and GF(q)[x]/(xⁿ) (Galois-field arithmetic) — in C, Python, Verilog and VHDL. Each implementation is checked against an independent golden model and published with its verification record. Getting started · Compare generation models · More about the library
