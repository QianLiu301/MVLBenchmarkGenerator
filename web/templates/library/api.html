JSON API v{{ api_version }}

Read-only, no key, no rate limit beyond ordinary fair use, CORS open. Everything the library publishes is reachable as JSON, so a script can select benchmarks, read verification records and fetch source files. Files are CC BY 4.0 — cite the entry in CITATION.bib.

Endpoints

EndpointReturns
GET /api/v1/benchmarksFilterable list of specifications
GET /api/v1/benchmarks/<slug>One specification with all its implementations
GET /api/v1/statsCounts, facet values, model pass rates, release and version info
GET /benchmark/<slug>/spec.jsonThe same specification as it ships inside archives
GET /benchmark/<slug>/<id>/downloadOne implementation's source file (plain text)
GET /benchmark/<slug>/<id>/logIts simulator log (plain text)
GET /benchmark/<slug>/downloadZIP with every file of that specification
GET /library/download-allZIP of the whole library; accepts the same filters

Fetch every verified VHDL file

import requests, pathlib

api = "https://llm-mvl.com/api/v1/benchmarks"
rows = requests.get(api, params={"language": "vhdl", "full": 1, "limit": 200}).json()

for b in rows["benchmarks"]:
    for i in b["implementations"]:
        if i["language"] == "vhdl" and i["verified"]:
            code = requests.get(i["download_url"]).text
            pathlib.Path(i["filename"]).write_text(code, encoding="utf-8")
            print(b["slug"], i["model"] or i["source"], i["verification_strength"])

Notes

  • The library changes when submissions are approved; /api/v1/stats reports the current counts and the release version. For a fixed dataset use the archived release on Zenodo, not the API.
  • Implementations that failed verification are included with "verified": false and their failure status; filter on that field if you only want correct designs.
  • sha256 is over the file's exact bytes, so a download can be checked against the record.
  • Breaking changes get a new prefix (/api/v2/…); fields may be added to existing responses without notice.
