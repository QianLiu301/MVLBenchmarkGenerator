Reading the numbers

  • Each cell counts implementations, not specifications: a model may have several implementations of one specification in one language when it was run more than once.
  • Coverage differs between models — a model that was only asked for HDL has no C or Python column. Compare models on the same language and family.
  • The specification prompt is identical for every model; sampling settings follow each provider's defaults (GPT-5 only allows temperature 1). The responding model name comes from the provider's response, not from the request.
  • External submissions are only published when they pass, so the human-authored row is not a failure rate.

Models and counts are listed on the acknowledgements page; browse the implementations themselves in the library.
