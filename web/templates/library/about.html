About the MVL Benchmark Library

The MVL Benchmark Library is an online resource for benchmarks within the domain of Multi-Valued Logic (MVL) design. It provides a database of benchmark specifications (module type, radix k, bitwidth, algebraic structure, operation set) together with implementations in C, Python, Verilog and VHDL, each carrying a machine-checked verification record.

What makes an entry

  • Specification — identified by a stable name such as alu_k3_8t (module, radix, digits). It fixes the algebraic structure: GF(p) for prime k, GF(pⁿ) for prime powers, and the integer ring Z/kZ otherwise.
  • Implementation — one source file realising the specification. Several implementations may exist per language, e.g. produced by different LLMs, so that models can be compared on identical specifications.
  • Verification record — the implementation is compiled and simulated (gcc, CPython, Icarus Verilog, GHDL); every test vector it prints is compared digit-wise with an independent, deterministic golden model. Only the result is stored; nothing is hand-edited.

How the library grows

Entries originate from an LLM-based generation pipeline described in the associated ISMVL 2026 paper: a natural-language or parametric specification is turned into code by a large language model, then simulated and validated. The generator is available on this site (Generate). Public submission of externally authored benchmarks, with automated checks followed by human review, is planned as the next step.
